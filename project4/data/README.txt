The course brief specifies the IMDB 5000 Movie Dataset (movie_metadata.csv).

The app automatically attempts to download a public mirror on first use if the file
is missing. For a fully offline submission, place the CSV here with this exact name:

    project4/data/movie_metadata.csv

The expected columns are the standard IMDB 5000 fields such as movie_title, genres,
title_year, duration, language, content_rating and imdb_score.
