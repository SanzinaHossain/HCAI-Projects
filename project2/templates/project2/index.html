Project 2

Explain an AI classifier without needing to be an AI expert

This project predicts penguin species. The interface lets you see how simple or complex the model is, ask “what would need to change?”, and inspect how each measurement influences predictions.

What is this project doing?

The dataset contains penguins from three species: Adelie, Gentoo, and Chinstrap. A model sees measurements such as bill length, bill depth, flipper length, and body mass, plus island, sex, and year, and learns to predict the species.

The main question is not only “Is the prediction correct?” but also “Can a person understand why the model behaves this way?”

Field guide

What every dataset field means

Species

The category the model tries to predict: Adelie, Gentoo, or Chinstrap.

Island

The Antarctic island where the penguin was observed: Biscoe, Dream, or Torgersen.

Sex

The recorded biological sex in the dataset. Missing values are shown as “Unknown”.

Year

The collection year (2007–2009). In this project it is treated as a category because the brief identifies four measurement features as numerical.

Bill length (mm)

The straight length of the penguin’s bill, measured in millimetres.

Bill depth (mm)

How deep/thick the bill is, measured in millimetres.

Flipper length (mm)

The length of the penguin’s flipper, measured in millimetres.

Body mass (g)

The penguin’s body weight in grams.

How do I read the tree?

Start at the top box. Follow the left or right branch depending on whether the rule is true. Continue until you reach a leaf. The “class” at that leaf is the model’s prediction.

Why does logistic regression use a different complexity measure?

For trees, Ω is the number of leaves, exactly as the brief specifies. For logistic regression, this implementation uses the number of non-zero coefficients. L1 regularization can set some coefficients to zero, so this measure directly counts how many learned feature weights are active.

Task 4

Counterfactual explanation

↑ Project home

A counterfactual answers a “what would need to be different?” question. You choose a real penguin and a target species. The system searches for nearby, realistic changes that would make the currently selected model predict that target species.

How are numeric and categorical fields changed?

Numeric measurements are sampled locally around the original value and kept inside the observed dataset range. Categorical fields (island, sex, year) are never given decimal noise; they either stay unchanged or switch to another category that really appears in the dataset.

Successful candidates are ranked using the required MAD-weighted L1 distance. Each categorical change adds one distance unit.

Task 5

Feature Effect Plots

↑ Project home

These plots explain the model globally instead of explaining only one penguin. Select one of the four numerical measurements. Both plots use the same model and λ currently selected above.

PDP

Shows the average predicted probability while the selected feature is varied across a grid. Each species gets its own curve.

ALE

Measures local changes in prediction and accumulates them. It is usually less distorted by correlated features than PDP.

How is ALE calculated for each model?

Logistic regression: the probability derivatives with respect to a numerical input can be computed analytically from the learned coefficients and softmax probabilities, so this project uses those exact partial derivatives before averaging and integrating them by ALE bins.

Decision tree: a tree produces stepwise predictions. Ordinary derivatives are zero almost everywhere and undefined at split boundaries, so a useful ALE must use a finite-difference discretization across bin edges.
